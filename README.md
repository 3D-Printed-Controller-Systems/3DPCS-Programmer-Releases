# Controller models for Designs

The 3D models the 3DPCS Controller Tool downloads for its Designs page. The app reads `models.json` and fetches the
pack it names; nothing here is meant to be opened by hand.

These files are made by 3D Printed Controller Systems for use with the 3DPCS Controller Tool only. All rights
